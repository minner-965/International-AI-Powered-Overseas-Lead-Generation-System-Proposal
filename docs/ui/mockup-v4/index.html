设计说明Design notes

沿用兄弟项目的商务工作台样式：深色侧栏 220px、白色顶栏、浅灰底与白色圆角卡片，主色蓝 #2563EB，状态色只用于状态。不使用渐变、发光、闪烁动画、装饰性大图标或外部字体与图标库。

双语排版Bilingual typography

中文为主读层，英文为同义辅读层：英文比同位中文小一档、常规字重、弱化色。导航、表头、KPI 与表单标签采用“中文在上、英文在下”；卡片标题、按钮、标签页与状态标签采用“中文后接小号英文”。手机端交互区域不小于 44px，表格改为“企业 + 阶段 + 下一步”的紧凑列表，点击进入详情。
