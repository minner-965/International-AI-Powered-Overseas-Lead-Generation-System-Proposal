# SIM外贸获客系统 · 飞书跟进记录配置步骤

完成以下 6 步后，系统中的每一条跟进活动、新任务、阶段变化、新线索和退订通知，都会自动新增为飞书多维表格中的一行。

需要准备：
- 飞书账号（建表的人需要是表格所有者或有“管理”权限）；
- 企业管理员协助审核应用（第 B 步）；
- 模板文件：`SIM跟进记录_导入模板.xlsx`（与本文件在同一目录）。

> 使用 Lark 国际版的企业：下文中的 `open.feishu.cn` 全部换成 `open.larksuite.com`，表格链接以 `larksuite.com/base/` 开头。

---

## A. 用模板建表

1. 打开飞书 → 云文档（云空间），选择 **新建 → 导入**（或在多维表格中选择“导入 Excel”），选择 `SIM跟进记录_导入模板.xlsx`，导入为 **多维表格**。只需导入“跟进记录”工作表；“说明”工作表供参考。
2. 导入完成后，逐列检查字段类型（点击列名 → **编辑字段**）：

| 列名 | 字段类型 | 可选值 |
|---|---|---|
| 同步编号 | 文本（保持为第一列） | — |
| 记录时间 | 日期，勾选显示时间，格式 `yyyy/MM/dd HH:mm` | — |
| 记录类型 | 单选 | 跟进活动、新任务、阶段变化、新线索、退订通知 |
| 企业 | 文本 | — |
| 国家 | 文本 | 例如 AE、MX、SA、US |
| 事项 | 单选 | 已发开发信、已发跟进邮件、收到回复、自动回复、退订、退信、需要跟进、电话、WhatsApp、会议、备注、手动邮件、报价、样品、跟进、回复处理、会议安排、移交、其他 |
| 阶段 | 单选 | 待联系、已联系、已回复、报价、样品、洽谈、成交、流失 |
| 内容 | 多行文本 | — |
| 负责人 | 文本 | — |
| 截止时间 | 日期，勾选显示时间，格式 `yyyy/MM/dd HH:mm` | — |
| 系统编号 | 文本 | — |

3. 把“记录类型 / 事项 / 阶段”改为 **单选** 后，建议按上表补齐全部选项（名称一字不差）。系统写入新选项时飞书也会自动补充，但提前建好颜色更整齐。
4. **删除导入的 4 行示例数据**（Al Noor Fashion Trading LLC、Moda Rivera S.A. de C.V. 等）。
5. 列名必须与上表完全一致，不要多空格；可以调整列宽、颜色和视图。

## B. 创建应用，获取 App ID / App Secret

1. 打开飞书开放平台 <https://open.feishu.cn/app> （开发者后台），点击 **创建企业自建应用**，填写名称（例如“SIM跟进记录同步”）和描述，保存。
2. 进入应用，左侧 **凭证与基础信息**：记下 **App ID**（形如 `cli_…`）和 **App Secret**。App Secret 相当于密码，只填到第 E 步的配置文件中，不要发到群聊或邮件。
3. 左侧 **权限管理**：搜索 `bitable:app`，开通“查看、评论、编辑和管理多维表格”。
4. 左侧 **应用发布 → 版本管理与发布** → **创建版本**：填写版本号（如 1.0.0）和更新说明；**可用范围** 需包含多维表格的所有者 → **保存** → **申请线上发布**。
5. 请企业管理员在飞书管理后台审核通过。审核通过后权限才生效。以后修改权限，需要重新创建版本并发布。

## C. 把应用加入多维表格

1. 打开第 A 步建好的多维表格，点击右上角 **…** → **…更多** → **添加文档应用**。
2. 搜索第 B 步创建的应用，添加并授予 **可编辑** 权限。
3. 如果表格开启了“高级权限”，需给该应用 **可管理** 权限，否则仍无法写入。

搜不到应用时：确认第 B 步的版本已审核通过、可用范围包含表格所有者、且已开通 `bitable:app` 权限。

## D. 从表格链接复制 app_token 和 table_id

打开表格，复制浏览器地址栏链接，例如：

```
https://xxx.feishu.cn/base/ABCdefGHIjkLMNopQRstUVwxyz?table=tblAbCdEf123456&view=vewXyZ
```

- `/base/` 后、`?` 前的一段 → **app_token**（示例中的 `ABCdefGHIjkLMNopQRstUVwxyz`）
- `table=` 后、`&` 前的一段（以 `tbl` 开头）→ **table_id**（示例中的 `tblAbCdEf123456`）

注意：链接以 `/wiki/` 开头的知识库表格，地址中的编号不是 app_token。请把表格建在云空间（链接为 `/base/…`），或联系技术人员换算。

## E. 填写系统配置并重启

在电脑上的项目目录中打开 `.env.phase7-outreach`，填写（替换为自己的值）：

```
CRM_PROVIDER=feishu
FEISHU_BASE_URL=https://open.feishu.cn
FEISHU_APP_ID=cli_xxx
FEISHU_APP_SECRET=xxx
FEISHU_BITABLE_APP_TOKEN=xxx
FEISHU_BITABLE_TABLE_ID=tblxxx
```

Lark 国际版：`FEISHU_BASE_URL=https://open.larksuite.com`。

保存后，在项目目录执行：

```
docker compose up -d --force-recreate outreach-worker
```

## F. 验证

1. 在系统中为任一企业记录一条 **电话** 跟进。
2. 1 分钟内，飞书表格中应出现一行：记录类型 = 跟进活动，事项 = 电话。
3. 没有出现时，按下表排查：

| 现象 / 提示 | 原因 | 处理 |
|---|---|---|
| 无权限、403、Forbidden | 未开通 `bitable:app`，或版本未发布/未审核 | 回到第 B 步开通权限并发布版本 |
| 无权限、403（权限已开通） | 应用未加入表格，或没有编辑权限 | 回到第 C 步添加文档应用并给“可编辑”；开启高级权限时给“可管理” |
| FieldNameNotFound、字段不存在 | 表格列名与系统配置不一致（多字、少字、空格） | 按第 A 步表格逐一核对列名 |
| 单选列出现多余选项或颜色杂乱 | 单选选项名称与系统写入值不一致 | 按第 A 步表格修正选项名称 |
| 应用凭证错误、invalid app | App ID / App Secret 填错，或国内版/国际版域名用错 | 重新复制凭证，核对 `FEISHU_BASE_URL` |
| 找不到表格、NOTEXIST | app_token 或 table_id 复制错误 | 按第 D 步重新复制 |

修改配置后，需再次执行第 E 步的重启命令。

## 可以改列名吗

可以。系统使用的列名统一保存在项目文件 `config/crm/feishu-bitable-map.json` 中，每一项右侧的 `"column"` 值就是飞书表格中的列名。若要把“企业”改成“客户名称”：先在飞书表格中改列名，再把该文件中对应的 `"column": "企业"` 改为 `"column": "客户名称"`，然后执行第 E 步的重启命令。左侧的英文键名不要修改。
